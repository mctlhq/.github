# Q4 2026 plan (to 2026-12-31)

Status: owner decisions recorded 2026-11-14. This file records what was
decided and what is still open. Live state stays in GitHub issues, the roadmap
manifests and DevLoop; this file does not change any epic or spike lifecycle.

It replaces the calendar of an earlier strategy draft (2026-11-13, not
committed). That draft was written from public sources only. It missed the
real state of #254, the existing external tenant and the security
precondition that blocks third-party repositories.

## Decisions (owner, 2026-11-14)

1. **Positioning.** "Governed agent operations" is the only positioning for
   Q4. MCTL is the governed layer between AI agents (Claude, Cursor, Codex,
   ChatGPT) and production:
   - the server holds the approval and binds it to the plan digest;
   - production gets the image digest that was verified in preview;
   - the agent and the approving human are separate principals.
   Target customer: teams of 5-50 engineers whose agents already write code
   but are not allowed near production.
2. **Pricing is not a Q4 objective.** The current goal is brand and B2B
   readiness, not monetisation.
3. **No freeze list.** Epics and spikes outside the active lines keep their
   lifecycle. The only rule is that at most three lines get active work.
4. **Active lines:**
   - #254 agent-deploy (P0);
   - #290, then #259 (P0, distribution);
   - Glovo M1 (P1; mctl-gitops#2457, mctl-api#954).

   #236 MCP gateway (G1 #237, G2 #238) moves to Q1. Support only, meaning
   only what an active line needs or what unblocks the release hold:
   - #181 and #281;
   - mctl-agents#993 and mctl-agents#1007;
   - the Temporal auth DAG (mctl-api#983, mctl-agents#1057,
     mctl-gitops#2570, mctl-gitops#2571).
5. **Egress.** New tenants onboarded for agent-deploy get internet egress off
   by default, with an explicit allowlist. Other new tenants keep the open
   default from mctl-gitops#2140 and mctl-api#789. Third-party repositories
   stay out of scope until this and the build-trust issues
   (mctl-gitops#1029, mctl-gitops#764) land.
6. **Design partner.** namax66 is the first design partner. The owner agrees
   the pilot scope with them directly.

## Objectives to 2026-12-31

- **O1.** Governed deploy works end-to-end on tenant-owned repositories:
  - #254 grants land, and `confirm="yes"` is removed;
  - promote by digest, a post-sync health gate, and a DeployRecord;
  - a demo on two reference repositories (Node, Go);
  - a security test of the main scenario with zero successful approval
    bypasses, plan swaps or replays.
- **O2.** One real design partner deploys one service from its own repository
  through the agent flow. Five discovery conversations with target-segment
  teams.
- **O3.** Ready to distribute:
  - the #290 verdict by 2026-11-28;
  - landing copy rewritten around the promise, plus a short demo;
  - the #259 package ready, submitted in January after owner review.
- **O4.** At most three active lines.
